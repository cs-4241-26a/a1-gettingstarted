This was a simple project, displaying my basic ability to make some HTML and CSS work together 
and host it on Render. I provided information about myself and styled it to give it extra color. 
Simple edits were made to package.json and server.js, but most of the work went to index.html 
and style.css. 

This README is in .txt because i like it a bit more than .md. Renamed the original README.md
to instructions.md so that i could continue to reference it. 


### TECHNICAL ACHIEVEMENTS: ###
Styled page using CSS. Style rules used: text-align, color, background-color, border, padding.
These rules were applied to *, h1, h2, p, and li.  


### DESIGN ACHIEVEMENTS: ###
Created a color palette using color.adobe.com in order to give the website some warm and cozy colors, 
as well as to make the headers pop more. The color wheel can be found in the file "adobe-color-palette.png", 
and the color values can be found in style.css as a comment at the top of the file.
